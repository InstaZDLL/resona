## LAME (MP3 encoding)

MP3 output uses the [LAME](https://lame.sourceforge.io/) encoder, built from
source and linked statically into `resona.exe` through the
[`mp3lame-sys`](https://github.com/DoumanAsh/mp3lame-sys) and
[`mp3lame-encoder`](https://github.com/DoumanAsh/mp3lame-encoder) crates.
LAME is licensed under the GNU Lesser General Public License; the full text
is in [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

Resona's complete source code is available at
<https://github.com/InstaZDLL/resona>, so you can rebuild `resona.exe` with a
modified version of LAME (change the `mp3lame-sys` dependency and run
`cargo build --release -p resona`). LAME's own source is available from the
LAME project and is bundled in the `mp3lame-sys` crate.

## Services

Resona reads public data from the [Deezer API](https://developers.deezer.com/api)
(extra tags), [LRCLIB](https://lrclib.net) (lyrics) and the Spotify desktop
client's own command-line tool (`spotify_cli`). It does not bundle any of
their content.
