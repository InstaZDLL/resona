# Resona 0.2.0 — corrections de lecture et d’affichage

Cette version corrige les nouveaux enregistrements FLAC qui résistaient au déplacement dans la piste avec PotPlayer, et améliore la fiabilité de la fenêtre et du mode playlist.

## Corrections

- **Recherche dans les FLAC.** L’encodeur évite les trames prédictives anormalement grandes observées sur des captures 24 bits. Les nouveaux fichiers contiennent aussi un index de lecture toutes les dix secondes. Le son décodé reste identique à la capture quantifiée.
- **Fenêtre.** Le rendu GPU évite les zones transparentes après le retour au premier plan. Le rendu logiciel reste disponible si OpenGL ne démarre pas. Le rendu GPU utilise davantage de mémoire.
- **Playlists.** Resona lit les sorties volumineuses de `spotify_cli` pendant son exécution, ce qui évite un blocage sur les réponses JSON. Lorsque Spotify est ouvert mais en pause, l’interface ne le signale plus comme fermé. Une panne de connexion de l’outil Spotify affiche maintenant son erreur réelle au lieu d’un simple délai dépassé.

Les anciens FLAC ne sont pas réencodés par cette mise à jour. Le script `scripts/repair-flac-seektable.ps1` peut leur ajouter un index, mais ne répare pas les trames audio anormales déjà présentes.

## Installer

Téléchargez **`resona_0.2.0_x64-setup.exe`** ci-dessous. `SHA256SUMS.txt` contient son empreinte SHA-256. L’installation se fait pour l’utilisateur courant, sans droits administrateur.

> [!NOTE]
> L’installateur est signé avec un certificat autosigné. Windows peut donc encore afficher un avertissement SmartScreen.

## Limitation connue

Sur Spotify Desktop 1.3.3.264, nous avons observé `spotify_cli status --format json` échouer avec `client connection failed` alors que Spotify lit la playlist normalement. Tant que l’outil fourni par Spotify ne répond pas, Resona ne peut pas démarrer automatiquement une playlist. Vous pouvez démarrer un enregistrement libre dans Resona, lancer la playlist dans Spotify puis arrêter l’enregistrement manuellement.
