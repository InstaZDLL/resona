# Resona 0.2.0 — playback and display fixes

This release fixes seeking in new FLAC recordings with PotPlayer and improves the reliability of the window and playlist mode.

## Fixes

- **FLAC seeking.** The encoder avoids abnormally large predictive frames observed in 24-bit recordings. New files also include seek points every ten seconds. Decoded audio remains identical to the quantized recording.
- **Window display.** GPU rendering prevents transparent areas when the window returns to the foreground. Software rendering remains available if OpenGL cannot start. GPU rendering uses more memory.
- **Playlists.** Resona drains large `spotify_cli` responses while the command runs, preventing a deadlock on playlist JSON. When Spotify is open but paused, the interface no longer reports it as closed. A Spotify CLI connection failure now shows its actual error instead of a generic timeout.

This update does not re-encode existing FLAC files. The `scripts/repair-flac-seektable.ps1` script can add seek points to them, but it cannot repair abnormal audio frames already in a file.

## Install

Download **`resona_0.2.0_x64-setup.exe`** below. Its SHA-256 checksum is in `SHA256SUMS.txt`. The installer runs for the current user without administrator privileges.

> [!NOTE]
> The installer is signed with a self-signed certificate, so Windows may still show a SmartScreen warning.

## Known limitation

On Spotify Desktop 1.3.3.264, we observed `spotify_cli status --format json` fail with `client connection failed` even while Spotify played a playlist normally. Resona cannot start a playlist automatically until Spotify's bundled CLI responds. As a workaround, start a manual recording in Resona, play the playlist in Spotify, then stop the recording manually.
