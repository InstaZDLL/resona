# Resona 0.4.1 — Partial tracks and security updates

This patch discards tracks stopped midway again, and updates the libraries Resona uses to fetch track information over HTTPS.

## Fixed

- **A track stopped midway could be kept as complete.** When Spotify's window title changed a moment before its media information, the new track lost the length and album Spotify gave it. Without its length, Resona could not tell a complete track from a cut-off one: a 3:30 track stopped after 23 seconds was saved as if it were whole. Such tracks are discarded again, unless you keep partial tracks.
- **The album came back with the length.** The same tracks also lost their album, which Resona uses to look up tags and to tell whether Spotify inserts a gap before the next track.
- **Playing the same track again within a few seconds could mix up its details.** Going back to a track just after leaving it (A, B, then A again) could give the first play's details to the second, or place its start wrong.

## Security

- **HTTPS certificate checks.** The libraries Resona uses to verify HTTPS certificates could accept certificates chained through emSign intermediates whose private keys are now public ([RUSTSEC-2026-0381](https://rustsec.org/advisories/RUSTSEC-2026-0381), [RUSTSEC-2026-0382](https://rustsec.org/advisories/RUSTSEC-2026-0382)). They secure every connection Resona makes: tag lookups on Deezer, cover art, lyrics on LRCLIB and the update check on GitHub. An active network attacker able to impersonate those servers could see the lookups (track titles and artists), return forged tags, lyrics or covers, and make the update notice link to a page of their choosing. No account or personal data is sent over these connections. Both libraries are updated.

## Changed

- **MP3 encoder updated** to the latest LAME bindings. Checked on 320 kbps recordings: files decode cleanly, with their tags and cover art.
- Other library updates.
- **Dependencies are now checked against the RustSec advisory database** on every push and pull request, daily, and before each release. A release is not built while `cargo audit` reports a known vulnerability.

## Install

Download **`resona_0.4.1_x64-setup.exe`** below. Its SHA-256 checksum is in `SHA256SUMS.txt`. The installer runs for the current user without administrator privileges.

> [!NOTE]
> The installer is signed with a self-signed certificate, so Windows may still show a SmartScreen warning.
