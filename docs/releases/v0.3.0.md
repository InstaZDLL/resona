# Resona 0.3.0 — Liked Songs, tempo and key

This release records your Liked Songs in playlist mode, tags every track with its tempo and musical key, keeps each track at its full length so synced lyrics line up, fills the link field from the clipboard, keeps Spotify at full volume during a playlist, and shows the version in the settings.

## New

- **Liked Songs in playlist mode.** Paste `https://open.spotify.com/collection/tracks` (or `spotify:collection:tracks`) and press **Record it**: Resona loads every liked track and records them in order.
- **Tempo and musical key tags.** Each track gets its BPM and key from Spotify's catalogue, for the release that actually played: `BPM` and `INITIALKEY` in FLAC, `TBPM` and `TKEY` in MP3 and WAV. The key uses the standard notation (`E`, `C#m`) that DJ software and music libraries read.
- **Links from the clipboard.** Copy a Spotify playlist, album, track or Liked Songs link, then switch to Resona: the link field fills itself. The clipboard is read only while a Resona window is in the foreground, never in the background, and never during a recording.
- **About section.** Settings → Interface now shows the installed version, the licence and a link to the source code on GitHub.

## Fixed

- **Track length and synced lyrics.** Resona trimmed the silence at the start and end of every track, so files came out up to 1.5 s shorter than the track's length on Spotify, and synced lyrics ran early when the start was trimmed. Each file now keeps the track's own leading and trailing silence: its length matches the catalogue, which lyrics sites and players rely on, and `.lrc` timings line up. Tracks recorded before 0.3.0 are not changed.
- **Spotify's volume during a playlist.** Spotify did not always keep the 100 % volume Resona set before starting the list, which scaled the recordings and made them not lossless. Resona now checks the volume on every new track and sets it back to 100 % when needed.

## Install

Download **`resona_0.3.0_x64-setup.exe`** below. Its SHA-256 checksum is in `SHA256SUMS.txt`. The installer runs for the current user without administrator privileges.

> [!NOTE]
> The installer is signed with a self-signed certificate, so Windows may still show a SmartScreen warning.
