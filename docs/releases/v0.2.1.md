# Resona 0.2.1 — FLAC seeking fix

This patch replaces the FLAC encoder after recordings made with 0.2.0 still failed to seek in PotPlayer. New recordings use libFLAC and include a valid PCM checksum. A real 24-bit recording was tested in PotPlayer: seeking to 1:01 resumed playback, and the decoded PCM matched the original recording exactly.

The update affects new recordings. FLAC files already recorded with 0.2.0 are not changed during installation and may need to be re-encoded to restore seeking. The previous seek-table repair script does not fix their audio frames.

## Install

Download **`resona_0.2.1_x64-setup.exe`** below. Its SHA-256 checksum is in `SHA256SUMS.txt`. The installer runs for the current user without administrator privileges.

> [!NOTE]
> The installer is signed with a self-signed certificate, so Windows may still show a SmartScreen warning.
