# Resona 0.3.1 — Playlists start at once

This patch makes long playlists start right away and shows track lengths the way Spotify does.

## Fixed

- **Long playlists start at once.** Resona looked up every track's length before starting playback: about 8 seconds for a 943-track playlist, during which nothing happened and the list did not show. The list now appears and Spotify switches to it within a couple of seconds, even while another playlist is playing; the lengths fill in while it plays.
- **Track lengths match Spotify's.** Lengths were cut down to the second, so a complete 203.7 s recording read 3:23 where Spotify shows 3:24, as if a second were missing. Recorded lengths are now rounded to the nearest second. Lengths of tracks still waiting come from Spotify's command-line tool, which only gives whole seconds, and can still read one second short until the track is recorded.

## Install

Download **`resona_0.3.1_x64-setup.exe`** below. Its SHA-256 checksum is in `SHA256SUMS.txt`. The installer runs for the current user without administrator privileges.

> [!NOTE]
> The installer is signed with a self-signed certificate, so Windows may still show a SmartScreen warning.
